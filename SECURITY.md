# Security policy

Tripinator is a small self-hosted project maintained by one person. Only the
latest commit on `main` (the version that is deployed) receives fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Report them
privately via GitHub's private vulnerability reporting instead:

https://github.com/connor935/tripinator/security/advisories/new

Include what is affected, how to reproduce it, and the impact you expect.
This is a hobby project, so please allow a few days for an answer. Once a
fix is deployed, the advisory can be published with credit to you if you
like.

## Scope

In scope: the application code in this repository and its container
images. Out of scope: the deployment infrastructure (not part of this
repository), denial of service, and findings that need physical access or
an already compromised account.
